PUT YOUR FILES HERE

showreel.mp4   60-90 second reel (plays muted on the homepage; button turns sound on)
portrait.jpg   optional photo for the About page (4:5 works best)
thumbs/        optional project thumbnails; point to them with "thumb" in js/data.js

HOW TO EDIT (VS Code)
- Text, projects, services, quotes, links, booking URL: js/data.js
- Colors, fonts, spacing: css/style.css (variables at the top)
- Page-specific copy (About story, headlines): the matching .html file
- Run it: install the "Live Server" extension, right-click index.html, "Open with Live Server"
- Contact form: create a free form at formspree.io and paste its URL into formAction in js/data.js

NEW: ONE CONTINUOUS SCROLL
index.html is the whole site (intro, showreel, work, about, services, proof, contact). Nav links scroll to each section.
Movie intro frames (optional): export from DaVinci as frames/frame_001.webp ... frame_120.webp. Without them a built-in animation plays.
Music: starts when the visitor clicks "Enter with sound" and only stops when they click the Sound button.
